# SarVita Arc

A SarVita-branded SillyTavern frontend for power users, with the original chat workspace, authentication flow, API surface, and responsive SarVita Arc presentation layer.

## Highlights

- SarVita Arc branding layered onto the SillyTavern interface.
- Responsive desktop and mobile layout support.
- Original frontend functionality preserved, including chat, plugins, API routes, and authentication.
- Browser-ready `public/lib.js` bundle generated by the project build.
- Homepage feature video embedded responsively without changing the video’s native aspect ratio.

### Homepage video

The main interface includes a muted, inline, looping feature video with native controls. The video is loaded from:

<https://files.catbox.moe/lbr5xd.mp4>

It uses `preload="metadata"`, `playsinline`, and responsive sizing so it remains usable on phones and desktop screens while avoiding layout distortion.

## Development

Requirements:

- Node.js 20 or newer
- npm

Install dependencies and build the browser bundle:

```bash
npm ci
npm run build
```

Start the application locally:

```bash
npm start
```

The primary local routes are:

- `/` — SarVita Arc main interface
- `/login` — login page
- `/api/ping` — serverless health check
- `/lib.js` — browser bundle
- `/script.js` — frontend bootstrap and application logic
- `/style.css` — primary stylesheet

## Vercel deployment

The repository includes `vercel.json` routing for the static `public/` assets and serverless handlers under `api/`. Production deployments should build the project bundle before deploying the prebuilt output.
